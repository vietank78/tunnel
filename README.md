# Auto Miner (Fabric 1.21.11)

Phim: F12 = mo menu, G = bat/tat (doi trong Controls). `/am menu` cung mo menu.

Lenh (client):
- `/am toggle`  bat/tat
- `/am pos1` / `/am pos2`  chon vung (nhin vao block hoac dung tai cho)
- `/am clear`  quay lai che do 3x3 truoc mat
- `/am fix true|false`  tu gui `/fix` khi cuc < 30%
- `/am status`

Build: push len GitHub -> tab Actions -> tai artifact `autominer-mod`.
Yeu cau: Fabric Loader >= 0.18.1 + Fabric API.
Luu y: nhieu server cam mod tu dong hoa, hay dung o singleplayer hoac noi cho phep.
